# Sokolov Training — Демонстрационный сайт персонального фитнес-тренера

Адаптивный одностраничный сайт (landing page) для вымышленного персонального фитнес-тренера, разработанный как демонстрационный проект для портфолио веб-разработчика.

> **Важно:** все персонажи, контактные данные, описания услуг и форма записи являются исключительно демонстрационными. Проект работает полностью на стороне клиента без базы данных, регистрации, платежей, серверного backend и платных API.

## Технологический стек

- **React 19** + **TypeScript**
- **Vite**
- **Tailwind CSS v4** (`@tailwindcss/vite`)
- **Motion** (`motion/react`) для плавных анимаций с поддержкой `prefers-reduced-motion`
- **Lucide React** для минималистичных UI-иконок
- **Семантическая HTML5-разметка** (`header`, `nav`, `main`, `section`, `article`, `footer`) и доступность (`aria-expanded`, `aria-controls`, `focus-visible`)

## Структура страницы

1. **Header** — фиксированная компактная навигация с рабочей кнопкой мобильного меню и переходом к форме.
2. **Hero** — крупный заголовок, краткое позиционирование, кнопка «Записаться» и редакционный визуал студии.
3. **Обо мне** — нейтральное демонстрационное описание методики вымышленного тренера без вымышленных достижений и отзывов.
4. **Услуги** — персональные тренировки, онлайн-сопровождение и разовая консультация с автоматическим выбором формата в форме.
5. **Этапы сотрудничества** — 4 последовательных шага взаимодействия.
6. **FAQ** — интерактивный доступный аккордеон с ответами на организационные и демонстрационные вопросы.
7. **Контакты** — демонстрационные реквизиты (`mailto:`, `tel:`) и клиентская форма с валидацией и подтверждением ввода без отправки на сервер.
8. **Footer** — дисклеймер демонстрационного проекта, ссылки на разделы и кнопка возврата наверх.

## Локальный запуск

Требуется установленный **Node.js 20+**.

1. Установите зависимости:
   ```bash
   npm install
   ```

2. Запустите сервер разработки:
   ```bash
   npm run dev
   ```
   Приложение запустится на `http://localhost:3000`.

3. Проверьте TypeScript и production-сборку:
   ```bash
   npm run lint
   npm run build
   npm run preview
   ```

## Публикация

### Вариант 1: Vercel или Netlify (рекомендуется)
1. Загрузите репозиторий на GitHub.
2. Импортируйте проект в **Vercel** или **Netlify**.
3. Параметры сборки:
   - **Build command:** `npm run build`
   - **Output directory:** `dist`

### Вариант 2: GitHub Pages
1. При публикации в подпапку репозитория укажите `base` в `vite.config.ts`:
   ```ts
   base: '/<repository-name>/',
   ```
2. Выполните `npm run build` и опубликуйте содержимое директории `dist/` через GitHub Actions или пакет `gh-pages`.
